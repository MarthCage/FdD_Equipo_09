# Descripción y Aportes de Tesis de Apoyo

## Tesis 1: Sistema de monitoreo ambiental basado en IoT para zonas rurales- PUCP
- **Universidad:** Pontificia Universidad Católica del Perú (PUCP)
- **Año:** 2018
- **Autores:** Huayap M, de Jesús DG
- **Descripción:** Propone un sistema de monitoreo ambiental basado en Internet de las Cosas (IoT), orientado a la supervisión de condiciones en zonas de difícil acceso. El sistema emplea sensores conectados a microcontroladores para la recolección de datos en tiempo real, los cuales son transmitidos a una plataforma digital para su visualización y análisis remoto, permitiendo el monitoreo continuo de variables ambientales sin intervención directa en campo.
- **Aporte al proyecto:**
  - Permite identificar una arquitectura base de IoT aplicable al sistema YuraGuard
  - Proporciona un modelo de integración de sensores, microcontroladores y comunicación inalámbrica
  - Demuestra la viabilidad del monitoreo remoto en zonas forestales de difícil acceso
  - Valida el uso de plataformas digitales para visualización y análisis de datos ambientales
- **Link:** https://tesis.pucp.edu.pe/items/a42150fb-3ed8-4742-96fc-1b59134b42e8

## Tesis 2: Detección de eventos mediante análisis de señales acústicas - UNMSM
- **Universidad:** Universidad Nacional Mayor de San Marcos (UNMSM)
- **Año:** 2016
- **Autores:** Dora CP
- **Descripción:** Propone un sistema de monitoreo acústico basado en sensores de sonido, enfocado en la detección de eventos ambientales mediante el análisis de señales acústicas. El sistema utiliza micrófonos conectados a microcontroladores para capturar audio del entorno, el cual es procesado mediante técnicas de análisis de frecuencia para identificar patrones asociados a actividad humana o alteraciones en el ambiente.
- **Aporte al proyecto:**
  - Sirve como base para el módulo de detección acústica del sistema YuraGuard
  - Valida el uso de sensores de audio y procesamiento de señales para identificar eventos
  - Demuestra la efectividad del análisis de frecuencia para detectar motosierras o intervención humana
  - Proporciona metodología para el procesamiento de señales acústicas con microcontroladores
- **Link:** https://cybertesis.unmsm.edu.pe/item/0ac3503c-710e-424a-a4f8-16cafef3b110
