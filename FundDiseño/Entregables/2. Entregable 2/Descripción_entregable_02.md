# Entregable 2 - Informe Técnico del Proyecto YURA GUARD

## Descripción

El informe técnico presenta el desarrollo del sistema YURA GUARD para la detección de tala ilegal en la Amazonía peruana.

-  Lista de exigencias 
-  Estructura de funciones 
-  Concepto de solución por dominio 
-  Bocetos de 3 conceptos de solución
-  Evaluación mediante Matriz de Pugh
-  Selección del concepto óptimo
-  Referencias bibliográficas
